
# 🎮 GameZone Retro

> A melhor loja de jogos clássicos da cidade! 🕹️

O **GameZone Retro** é uma página web simples desenvolvida para apresentar um catálogo de consoles nostálgicos e uma tabela com preços de jogos clássicos que marcaram época.

## 🚀 Sobre o Projeto

Este projeto foi criado como uma atividade prática para demonstrar conceitos fundamentais de estruturação HTML, tais como:
- Formatação de texto (`<strong>`, `<em>`)
- Links internos de ancoragem (`<a href="#precos">`) e links externos
- Exibição de imagens
- Listas não ordenadas (`<ul>`, `<li>`)
- Tabelas de dados (`<table>`, `<thead>`, `<tr>`, `<td>`)

---

## 📂 Estrutura da Página

A página do **GameZone Retro** contém as seguintes seções:

1. **Cabeçalho:** Apresentação da loja com título principal, descrição e links rápidos.
2. **Consoles Disponíveis:** Lista contendo os videogames clássicos oferecidos (NES, SNES, Sega Genesis, Atari 2600).
3. **Tabela de Preços:** Relação detalhada com títulos de jogos, suas respectivas plataformas e valores em R$.
4. **Rodapé:** Direitos autorais e identificação do projeto.

---

## 💡 Dicas de Aprimoramento do HTML

Para deixar o código ainda mais correto de acordo com os padrões da W3C, aqui vão algumas sugestões rápidas:

* **Tag `<ul>`:** Certifique-se de que todas as tags `<li>` fiquem *dentro* da tag `<ul>...</ul>` para manter a lista bem estruturada.
* **Estrutura da Tabela:** A tag `<tbody>` deve envolver as linhas (`<tr>`) de conteúdo dentro da tabela, e o encerramento da tag `</table>` deve vir antes do fechamento do `</body>`.
